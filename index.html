02Scope

What I test

Five surfaces, one question every time: where does this system trust something it shouldn't?

Broken access control, business logic and authentication. The bugs that need someone to understand how the app is supposed to work first.

  • IDOR and privilege escalation
  • Business logic and race conditions
  • OTP, password reset and session flaws
  • XSS chains to account takeover
  • Price and checkout manipulation
  • SSRF and open redirects

From my reports

Double door IDOR exposing 85k+ emails Self XSS to stored XSS and mass account takeover Breaking the checkout with price manipulation

REST and GraphQL, tested request by request. Most of the serious bugs I find live in endpoints the interface never calls the way an attacker would.

  • BOLA and broken function level authorization
  • Mass assignment
  • Excessive data exposure
  • Rate limits and enumeration
  • GraphQL introspection and batching
  • Verbose errors and stack traces

From my reports

Profile update to account takeover, a mass assignment story The art of request manipulation API security testing, my guide on Unihackers

The app and the API behind it. I take the APK apart, then watch every request it makes once pinning is out of the way.

  • Exported activities, services and deep links
  • Insecure local storage
  • Hardcoded keys and secrets
  • WebView and intent issues
  • Certificate pinning bypass
  • Backend APIs the app hides

Where it shows up

    85,000+ emails, one URL away

    Target
    Not disclosed
    Found with
    URL manipulation
    Outcome
    Fixed after report

    Changing references in a URL returned other users' records. Followed all the way through, the exposure added up to more than 85,000 email addresses.

    Another company's bundle, at ten times the price

    Target
    Not disclosed
    Found with
    One numeric ID
    Outcome
    Fixed after report

    Swapping a bundle ID let me view, edit and delete another company's service bundle, including changing its price from 6,600 to 66,000.

  4. Case 04Mass assignment

    One extra field, a whole account

    Target
    Not disclosed
    Found with
    Request tampering
    Outcome
    Fixed after report

    The profile update endpoint accepted more fields than the form ever sent. Adding the right one to the request turned an everyday update into an account takeover.
